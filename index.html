한자 찾기 AR · 게임 만들기

찾을 한자와 숨길 자리를 정하면, 학생에게 보낼 링크와 QR 코드를 만들어 줍니다.

다른 게임 불러오기 (링크·백업 파일)
처음이신가요? 사용 순서 보기
  1. 1. 기본 설정에서 제목과 찾는 방식을 고릅니다.
    • 걸어 다니며 찾기: 운동장·교정의 실제 장소에 숨깁니다. 학생은 GPS로 그곳까지 걸어가서 잡습니다(실외).
    • 제자리에서 둘러보며 찾기: 학생 주위의 앞뒤·좌우·위아래에 숨깁니다. 학생은 선 자리에서 휴대폰을 돌리며 찾습니다(교실·실내, GPS 필요 없음).
  2. 2. 한자 고르기: 중학교·고등학교 900자 목록에서 누르거나 무작위로 뽑고, 직접 입력할 수도 있습니다.
  3. 3. 숨길 자리: 걸어 다니며 찾기는 지도에서 찍거나 ‘흩뿌리기’로 한꺼번에, 제자리는 ‘고르게 펼치기’ 등으로 정합니다.
  4. 6. 학생에게 보내기에서 링크·QR 만들기를 누르고, QR을 칠판 화면에 크게 띄우거나 링크를 보냅니다.

준비는 한 번만 · 이 파일을 index.html이라는 이름으로 GitHub Pages 같은 https 주소에 한 번 올리고, 그 주소로 이 편집 화면을 엽니다. 그다음부터는 게임을 새로 만들어도 파일을 다시 올릴 필요 없이 링크·QR만 바꿔 주면 됩니다(게임 내용이 링크 안에 들어 있음). 파일을 컴퓨터에서 직접 열면 링크는 만들 수 있지만, 학생 링크의 앱 주소는 직접 적어야 합니다.

개인정보 · ‘학생 결과 모으기’를 쓰지 않으면 학생 이름과 기록은 학생 휴대폰에만 저장됩니다. 쓰면 선생님의 구글 시트로 이름·학번·찾은 한자·오답이 전송됩니다.

1. 기본 설정

방향 안내를 끄면 찾기가 어려워집니다. 끄더라도 학생이 ‘쉬움’을 고르면 켜집니다.

2. 한자 고르기 (고른 한자 0자)

누르면 넣고, 한 번 더 누르면 뺍니다. 훈음은 한자 채집기(kkalssak-gif/hanja)에 정리된 목록을 따릅니다. 넣은 뒤 아래 한자 목록에서 고칠 수 있습니다.

4자까지 넣을 수 있어 한자어·성어 찾기로도 쓸 수 있습니다.

스프레드시트에서 한꺼번에 붙여넣기

엑셀·구글 시트에서 아래 순서의 열을 복사해 붙여넣으세요(첫 줄이 ‘한자’로 시작하면 제목 줄로 보고 건너뜁니다). 한자·훈음 외에는 비워도 됩니다.

3. 지도에 숨기기

지도를 누르면 그 자리에 새 한자를 추가할 수 있습니다. 핀은 끌어서 옮길 수 있고, 핀을 누르면 아래 목록에서 해당 한자로 이동합니다.

한꺼번에 놓기

지도를 운동장 가운데로 옮긴 뒤 누르세요. 한자끼리 겹치지 않게 무작위로 놓고, 핀을 끌어 다듬으면 됩니다.

3. 학생 주위에 숨기기

학생이 처음 바라본 쪽이 정면(0°)입니다. 오른쪽으로 돌수록 90°(오른쪽), 180°(뒤), 270°(왼쪽)입니다. 높이는 위·정면·아래 세 가지입니다.

휴대폰으로 직접 놓기

휴대폰으로 이 화면을 열고 방향을 켠 뒤, 교실에서 한자를 둘 쪽을 바라보고 아래 목록의 ‘지금 보는 쪽에 놓기’를 누르세요.

4. 한자 목록 (0개)

선택한 한자 없음

5. 학생 결과 모으기 (선택)

비워 두면 학생 이름만 받고 기록은 학생 휴대폰에만 남습니다. 결과 수집 주소를 넣으면 시작할 때 이름·학번과 개인정보 동의를 받고, 찾은 한자·오답·힌트 기록을 선생님의 구글 시트로 보냅니다.

모둠으로 함께 모으기

켜면 학생이 시작할 때 모둠 이름을 적습니다. 같은 모둠 이름을 적은 친구들이 잡은 한자는 모두의 목록에 함께 채워지고, 모둠이 다 모으면 함께 끝납니다. 정한 인원이 차면 그 모둠에는 더 들어갈 수 없습니다. 결과 수집 주소가 있어야 동작하며, 이전 판 Code.gs를 쓰고 있다면 새 Code.gs로 바꿔 ‘새 버전’으로 배포해야 합니다.

결과 수집 주소 만드는 법 (처음 한 번)
  1. 구글 드라이브에서 새 구글 시트를 만들고, 메뉴 확장 프로그램 → Apps Script를 엽니다.
  2. 위의 Code.gs 내려받기로 받은 파일 내용을 편집기에 전부 붙여 넣습니다(원래 있던 내용은 지움).
  3. 맨 위 TEACHER_KEY의 값을 선생님만 아는 비밀번호로 바꾸고 저장합니다.
  4. 오른쪽 위 배포 → 새 배포 → 유형 웹 앱 → 실행 사용자 나, 액세스 권한 모든 사용자 → 배포. 처음에는 권한 허용 창이 뜹니다.
  5. 나온 웹 앱 주소(…/exec로 끝남)를 위 칸에 붙여 넣고 연결 확인을 누릅니다.

Code.gs를 고친 뒤에는 배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포로 올려야 주소가 바뀌지 않습니다. ‘새 배포’를 누르면 주소가 바뀌어 학생 링크를 다시 만들어야 합니다.

학생 기록은 시트의 ‘기록’ 탭에 쌓입니다. 학년말 등 보유 기간이 끝나면 시트의 행을 직접 지워 주세요.

6. 확인하고 학생에게 보내기

게임 내용을 고쳤다면 링크·QR을 다시 만들어 학생에게 새로 주세요. 같은 게임이라 학생이 찾은 기록은 이어집니다.

그 밖의 방법

게임 파일로 내려받으면 게임이 파일 안에 들어갑니다. 게임마다 따로 https 주소에 올리고 싶을 때 씁니다. 입력 내용은 이 브라우저에 자동 저장되며, 다른 컴퓨터로 옮기려면 백업 파일이나 링크를 쓰세요.

7. 학생 결과 보기
